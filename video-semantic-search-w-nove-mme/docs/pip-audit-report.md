## CDK Environment Findings

### pip 25.1.1 — 2 vulnerabilities

| CVE | Severity | Fixed In | Description |
|-----|----------|----------|-------------|
| CVE-2025-8869 | Medium | 25.3 | Tar archive extraction may not validate symbolic links on Python versions without PEP 706. Mitigated on Python >= 3.12 (this project uses 3.13.5). |
| CVE-2026-1703 | Medium | 26.0 | Maliciously crafted wheel archive could extract files outside the installation directory (limited to path prefixes of installation dir). |

**Risk Assessment: LOW (development-only tooling)**

Both CVEs affect `pip` itself — the package installer used during local development. `pip` is not deployed to Lambda; it is not part of the application runtime. The CDK venv is used only on developer machines to synthesize and deploy CloudFormation templates.

Additionally, CVE-2025-8869 is mitigated by using Python 3.13.5 (which implements PEP 706).

**Recommendation:** Update pip in the CDK venv:

```bash
cd cdk && source .venv/bin/activate && pip install --upgrade pip
```
